## The joke

> I bought the dip. Then the dip bought a shovel and kept digging.

A single joke about crypto and trading life, capped at 200 characters.
Every trader has been told to buy the dip — the punchline turns the dip
itself into the buyer, because the dip is never done dipping.

## How it works

`main.py` writes the joke to `/output/entry.txt` (UTF-8, plain text),
validating that the line is 1–200 characters and not only whitespace.

```sh
python3 main.py
```
